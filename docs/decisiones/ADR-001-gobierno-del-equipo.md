# ADR-001 — Gobierno del equipo de asistentes

**Fecha:** 6 de octubre de 2026 · **Decide:** el fundador · **Estado:** vigente

**Decisión:** Claude es el líder técnico (plan, arquitectura, métodos, fichas de tarea, revisión de PR). Codex, GitHub Copilot, Open Code y Antigravity ejecutan fichas de tarea con sus propios créditos. Cualquiera puede proponer cambios mediante RFC con evidencia; el fundador decide lo reservado a él y los desacuerdos.

**Motivos (palabras del fundador):** Claude ha detectado y corregido fallos de los otros asistentes; los créditos de Claude se agotan y hay que esperar a que se regeneren, así que conviene que Claude planifique y revise y que los demás gasten los suyos en ejecutar.

**Límites de esta decisión:** no sustituye las reglas de `CLAUDE.md`; no elimina la revisión humana del fundador; Claude también puede equivocarse (se registra en `LECCIONES.md`); si Claude no está disponible (sin créditos), el plan y las fichas siguen vigentes y los demás pueden seguir ejecutándolas; las dudas se anotan como RFC para cuando vuelva.
